StatusTimeline

One strip per platform. Cells are 6–16 px wide, latest on the right; the component shows as many recent runs as fit, up to 40. Keyboard: one Tab stop per strip (a horizontal listbox; aria-activedescendant); ← → move one run, Home and End jump to oldest and latest, ↑ ↓ move to the other strip on the same run. Focus stays on the strip. Pointer and touch: the whole 48 px strip is the target; press, hover or drag across it selects the nearest cell by x (touch-action: pan-y). Selection is a run: the same column is outlined in every strip and the panel below always shows it (latest by default; a page may pass initialRun; Test History passes the latest failing run). Results strips are always interactive; the runs strip never is (no interactive prop). The runs strip’s name uses the project’s default branch. Oldest label follows the TrendChart counting rule: the latest is “Latest”, the oldest of n shown is “{n−1} runs ago” (“1 run ago” at 2), so 40 cells read “39 runs ago”; more runs than fit still reads “Last {n} runs”. Before measurement the strip renders up to 40 cells clipped from the left and no oldest label. Flaky: passed and failed on the same commit and platform within 30 days.

12

TrendChart

Drawn in pixels at the real width, like Recharts: 12 px axis text and 13 px value labels at every size. Lines are fitted to the data and floor; bars start at zero. Project page window: the last 30 default-branch runs for every per-run chart (fewer when there are fewer; the caption says how many), stated in the scope line. Missing value (a platform didn’t run): the line breaks, a lone point between gaps is a 3 px dot, tooltip and table read “Not run” in --ink-3. Hover or focus a chart for the tooltip. Counting: the latest point is “Latest”; any other point is “{k} runs ago” (k = latest index − point index, “1 run ago” at 1), the same on the axis, tooltip and table, so the oldest of 30 is “29 runs ago”. Right margin = max(60, 8 + widest end label + 6) (phone max(44, …)), so end labels like “100.0%” never clip. Integer formats step by whole numbers; an all-zero series runs 0…1; x labels never repeat. Error: the plot area becomes an inset panel inside the same chart card (no card in a card); title and scope stay, caption and “Show table” are hidden.

ErrorState and Notice

ErrorState has two variants: page (whole-page failure, served by the server with HTTP 200, since a Next.js render can’t set 503; “Try again” is a link to the same URL, so it works without JavaScript; no onRetry) and inline (a client-side section: feed or table; “Try again” is a button calling onRetry). Notice is the page-level banner; it is never used inside a card. Props: tone, icon (clock · x-circle · lock), title (optional on every tone), body. Title 14.5/600 in the tone ink (neutral: --ink-2); body 14/1.5 --ink-2. A Notice rendered with the page has no live-region role; one inserted after load (a project going stale while the page is open) gets role="status".
