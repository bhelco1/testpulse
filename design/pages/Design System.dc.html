Foundations and components

Every token below is a CSS variable. Components use only these variables, so the theme switch changes the whole page. Figures come from the brief; anything not in §5 is tagged SAMPLE.

01

Color

Warm neutrals with one accent. Amber means a threshold or something that needs attention: floor markers, stale, empty, flaky, sample tags. Buttons and links use ink, not amber, so amber always carries meaning.

Contrast pairs

Worked out live from the token values. Every ink and status ink is checked on all four surfaces, and each status ink on its own tint; all need 4.5:1 (AA). Graphics such as bars and markers need 3:1. CI runs the same check against tokens.css.

09

Test pyramid

The main visual on the project page: centred bars with widths in proportion to test counts, from unit at the bottom up to E2E. Declared suites appear as a dashed outline and are excluded from the total. It can be built in plain HTML/CSS or with Recharts horizontal bars.

10

Coverage bar with floor

The scale always runs 0 to 100, so small headroom looks small. The amber tick is the floor enforced in CI. Below the floor, the bar turns amber and gets an arrow and a written gap.

11

Trend chart frame

Title, a caption that states the takeaway, the chart, and a data-table toggle. Lines are labelled directly, with no legend. Axis labels are plain words. A single run shows a dot and an explanation, never empty axes. Buildable in Recharts as a LineChart with a ReferenceLine for the floor.
